Sobre

A Mensagem Control v2.1.1

Feito para as equipes de mídia das igrejas do Tabernáculo da Fé.

Só para quem ajuda a testar: este computador recebe as versões novas antes das igrejas. Deixe desligado no computador do culto se não for testar.

Importar nova mensagem

Cada parágrafo deve começar com o número (ex: "54 Agora..." ou "[54] Agora..."). Parágrafos longos são divididos automaticamente para caber em 2 a 3 linhas.

Novo hino

Linha em branco = nova tela. Coloque o coro entre linhas com *. Tudo entre um coro e outro é uma estrofe; para separar estrofes sem coro no meio, comece com o número (2.).

A sequência aparece aqui enquanto você digita.

Importar hinos

Escolha a pasta com os hinos (ex: C:\tf_slides\1 Hinos). Cada subpasta vira uma categoria e cada arquivo .txt vira um hino: o nome do arquivo dá o número e o título (ex: "012 - Vinde, Povo do Senhor").

Atualizando o aplicativo

Baixando e instalando a nova versão. O programa vai fechar e abrir sozinho em instantes.
